# Interactive Study Planner Prototype

An interactive mobile app prototype designed for students to manage daily academic tasks efficiently. This project demonstrates modern UI/UX design principles, clickable navigation flow, smooth screen transitions, and a clean productivity-focused mobile interface created using Figma.

---

# Project Overview

The Interactive Study Planner Prototype is a modern student productivity application designed to help users organize assignments, manage schedules, and improve daily task planning.

This project was created as part of a UI/UX internship task to demonstrate:
- Interactive prototyping
- Navigation flow creation
- Mobile app UI design
- User-friendly experience design
- Modern interface styling

---

# Prototype Features

- Interactive clickable navigation
- Splash screen onboarding
- Login authentication screen
- Task management home screen
- Add Task functionality
- User profile screen
- Smooth screen transitions
- Modern minimal UI design
- Mobile-friendly layout
- Productivity-focused experience
